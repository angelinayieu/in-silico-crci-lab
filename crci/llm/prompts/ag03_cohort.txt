2. **Cancer Type (cancer_type)**: The primary cancer type studied. Use one of: breast, lung, colorectal, hematological, mixed_solid, general_population, any. If the study includes multiple cancer types, use "mixed_solid".

3. **Treatment Phase (treatment_phase)**: When in the cancer treatment trajectory were participants studied? Use one of: pre_treatment, during_treatment, early_post, late_post, survivorship, any.

5. **Percent Female (percent_female)**: The percentage of female participants (0-100 scale). If only male percentage is given, compute 100 - male%.

6. **Demographics Notes (demographics_notes)**: Any additional demographic information (ethnicity breakdown, education level, comorbidities, inclusion/exclusion criteria) as a brief summary.

- Extract ONLY what is explicitly stated in the text. Do not infer or hallucinate values.

- For N: prefer the analyzed sample size over the enrolled sample size if both are given.
- For cancer type: if the paper studies "cancer survivors" without specifying type, use "mixed_solid".
