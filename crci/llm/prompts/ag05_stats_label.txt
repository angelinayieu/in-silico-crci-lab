## THE 40 SPAN LABEL TYPES

You MUST use exactly one of these 40 label types for each extracted span:

### Primary Effect Measures (1-10)
1.  EFFECT_SIZE — Standardized effect size (Cohen's d, Hedges' g, Glass's delta, SMD)
2.  UNSTD_BETA — Unstandardized regression coefficient (b, B)
3.  STD_BETA — Standardized regression coefficient (beta, Beta)
4.  ODDS_RATIO — Odds ratio (OR, aOR)
5.  HAZARD_RATIO — Hazard ratio (HR, aHR)
6.  RISK_RATIO — Relative risk / risk ratio (RR, aRR)
7.  INCIDENCE_RATE_RATIO — Incidence rate ratio (IRR)
8.  MEAN_DIFFERENCE — Mean difference between groups (MD, WMD)
9.  PERCENT_CHANGE — Percentage change from baseline or between groups

### Precision and Interval Measures (11-16)
11. CI_LOWER — Confidence interval lower bound (always pair with CI_UPPER)
12. CI_UPPER — Confidence interval upper bound (always pair with CI_LOWER)
13. SE — Standard error of the estimate
14. SD — Standard deviation
15. P_VALUE — p-value (exact or inequality: p=0.03, p<0.001)
16. VARIANCE — Variance (sigma-squared)

### Central Tendency and Distribution (17-22)
17. MEAN — Mean / average value
18. MEDIAN — Median value
19. IQR_LOWER — Interquartile range lower bound (Q1, 25th percentile)
20. IQR_UPPER — Interquartile range upper bound (Q3, 75th percentile)

22. RANGE_MAX — Maximum value (range upper bound)

### Sample Information (23-26)

### Heterogeneity / Meta-Analysis (32-34)
32. I_SQUARED — I-squared heterogeneity statistic (I2, I-squared)

34. Q_STATISTIC — Cochran's Q statistic for heterogeneity

### Model Fit (35-37)

### Effect Modification (38-39)

### Temporal (40)

## EXTRACTION RULES

### MANDATORY REQUIREMENTS:
1. Extract EVERY numeric statistical result from the text
2. Provide EXACT character offsets (char_start, char_end) for each span
3. Assign a confidence score (0.0-1.0) reflecting how certain you are:
   - 0.9-1.0: Value is unambiguous and clearly labeled
   - 0.7-0.9: Value is clearly numeric but context requires some inference
   - 0.5-0.7: Value requires interpretation or is partially obscured
   - <0.5: Significant ambiguity about value or type
4. Use the EXACT text from the paper as span_text (do not modify)
5. When extracting CI bounds, ALWAYS extract both CI_LOWER and CI_UPPER as separate spans

### GROUPING:
- Use grouping_id to link related statistics (e.g., an effect size with its CI and p-value)
- Format: "grp_001", "grp_002", etc.
- All statistics from the same result should share a grouping_id
- Example: "OR = 1.5 (95% CI: 1.1-2.0, p = 0.01)" produces 4 spans with same grouping_id

### WHAT TO EXTRACT:
- All effect sizes, regression coefficients, odds/hazard/risk ratios
- All confidence intervals (as separate lower and upper bounds)
- All p-values (including "p < 0.001" or "NS")
- All means, SDs, SEs, medians, IQRs
- All sample sizes (total and per-arm)
- All test statistics (F, t, chi-square, z)
- All heterogeneity measures (I2, tau2, Q)
- All model fit statistics (R2, AIC, BIC)
- All interaction terms and subgroup effects
- Follow-up duration

### WHAT NOT TO EXTRACT:
- Reference numbers, citation counts, table/figure numbers
- Page numbers, participant IDs
- Dates (unless follow-up duration)
- Dosage values (those are for AG06)
- Measurement instrument scores without context

### FROM TABLES:
- Extract statistics from tables row by row
- Use the table context to determine label types
- Table column headers inform the label_type assignment
