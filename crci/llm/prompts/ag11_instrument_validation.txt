## EXTRACTION RULES

### MANDATORY REQUIREMENTS:
1. Extract EVERY psychometric property reported for EVERY instrument
2. Provide EXACT character offsets (char_start, char_end) for each span
3. Assign a confidence score (0.0-1.0) reflecting how certain you are:
   - 0.9-1.0: Value is unambiguous and clearly labeled
   - 0.7-0.9: Value is clearly numeric but context requires inference
   - 0.5-0.7: Value requires interpretation or is partially obscured
   - <0.5: Significant ambiguity about value or type
4. Use the EXACT text from the paper as span_text (do not modify)

### GROUPING:
- Use grouping_id to link properties to the SAME instrument and population
- Format: "inst_001", "inst_002", etc.
- ALL properties for the same instrument x subscale x population share one grouping_id
- Example: Cronbach's alpha, factor loadings, and N for FACT-Cog in breast cancer
  patients would all share "inst_001"

### WHAT TO EXTRACT:
- ALL Cronbach's alpha values (overall and per-subscale)
- ALL test-retest reliability coefficients
- ALL factor loadings (per item if available, or mean loading)
- Factor structure results (number of factors, fit indices: CFI, RMSEA, TLI)
- ALL convergent and discriminant validity correlations
- Measurement invariance / DIF results across cancer vs. non-cancer groups
- Standard error of measurement (SEM) if reported
- Sample sizes for each reliability/validity estimate
- Instrument names and subscale identifiers
- Population descriptors (cancer type, treatment phase, N)

### WHAT NOT TO EXTRACT:
- Raw item-level scores (individual questionnaire responses)
- Administration time / feasibility data
- Citation counts or reference numbers
- Page numbers, table/figure numbers
- Descriptive statistics for clinical outcomes (those are for AG05)

### FROM TABLES:
- Psychometric studies often present results in tables (e.g., "Table 2: Reliability by subscale")
- Extract each cell as a separate span with the correct label type
- Use table column headers to determine whether a value is alpha, loading, r_tt, etc.
